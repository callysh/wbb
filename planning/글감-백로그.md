# 글감 백로그 — 레인 B(공시·이벤트) + 레인 C(인용 공백)

`/bake 레이더`의 2차 입력이자 출력 저장소. 캘린더에 없는 글감은 전부 여기로 모인다.
채택되면 편성표로 옮기고 상태를 `편성`으로, 폐기하면 `폐기(이유)`로 바꾼다. 삭제하지 않는다 (같은 아이디어 재검토 방지).

점수 = 수요 + 공백 + 렌즈 + 타이밍, 각 0~2점 (기준은 `templates/프롬프트-레이더.md`). **5점 이상만 편성 후보.**
