# 브로드컴 실적 D+1 제목 5안 (검색형, 클러스터 ①) · 2026-09-03

차별화: 경쟁 기사는 전부 "예상 웃돈 실적 + 가이던스 실망 + 시간외 하락"의 동일 구성. 비어 있는 자리는 (a) 어떤 가이던스가 문제였는지(AI는 이겼고 총매출이 졌다) (b) 어제 D-1 예측의 검증 서사.

1. 브로드컴 실적 발표, AI 매출 221% 늘었는데 주가 하락한 이유는 '이 한 줄'
- 구조: 배열 3 / 메인 키워드: 브로드컴 실적 발표, 주가 하락 이유 / 타겟 질의: 브로드컴 주가 하락 이유
- 후킹: 221%(실제 수치) 대비 하락의 역설 + 가이던스 한 줄 암시

2. 브로드컴 주가 시간외 급락 이유, 가이던스 348억달러가 '실망'이 된 기준
- 구조: 배열 3 / 메인 키워드: 브로드컴 주가 급락 이유, 가이던스 / 타겟 질의: 브로드컴 시간외 급락 왜
- 후킹: 348억달러라는 큰 숫자가 왜 실망인지 (기준 = 컨센서스 350억)

3. "AI 예고편은 이겼다"... 브로드컴 실적 D+1, 주가를 가른 건 '다른 숫자'
- 구조: 배열 1 / 메인 키워드: 브로드컴 실적 / 타겟 질의: 브로드컴 실적 가이던스
- 후킹: D-1 글의 예측(갈림길은 AI 가이던스)을 스스로 검증하는 서사. 시리즈 연결형

4. "매출 86% 증가에도 시간외 7% 하락"... 브로드컴 실적 발표 후 주가가 흔들린 이유
- 구조: 배열 2 (피드형 성격) / 메인 키워드: 브로드컴 실적 발표, 주가 / 타겟 질의: 브로드컴 실적 발표 주가
- 후킹: 실제 수치 두 개의 충돌

5. 브로드컴 실적 가이던스 정리, 4분기 348억달러와 AI 217억달러 중 시장이 본 숫자
- 구조: 배열 3 / 메인 키워드: 브로드컴 실적 가이던스 / 타겟 질의: 브로드컴 4분기 가이던스
- 후킹: 두 가이던스 중 하나만 문제였다는 구조 예고. D-1 타겟 질의('브로드컴 실적발표 컨센서스')와 연속

추천 1순위: 1안. "브로드컴 실적 발표"가 발표 당일 최다 질의이고, 경쟁 기사는 '왜?'까지만 던지고 답을 제목에 안 담았다. 221%라는 실제 수치가 후킹을 대신하며 메인 키워드가 선두 9자 안에 들어간다. 3안은 예측-검증 서사가 강하지만 검색 매칭은 1안이 앞선다.
