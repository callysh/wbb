# 클러스터 2 프롬프트 — 재무제표 베이커리 (용어 × 티커 브릿지)

목적: 회계·투자 용어의 **롱테일 자연어 질의**를 잡는다. 핵심 키워드는 공식기관이 독식하지만, 롱테일로 갈수록 AI 브리핑이 블로거를 인용한다 (운영자 검증 완료).

---

## 프롬프트 A: 주제 발굴 (주간 기획 때)

```
너는 네이버 검색 수요 분석 어시스턴트다.
회계·투자 용어 "{예: 감가상각}"에 대해, 실제 사람들이 검색창이나 AI에 물어볼 법한
롱테일 자연어 질문을 10개 만들어줘.
조건: "뜻"만 묻는 질문 말고, 상황이 붙은 질문 위주로
(예: "감가상각 하면 현금이 나가나요?", "감가상각비 자동차 계산 예시").
공공기관(국세청 등) 사이트가 이미 완벽하게 답하는 질문은 제외해줘.
```

## 프롬프트 B: 재료 준비 (글 쓰기 전)

```
너는 회계 교육 콘텐츠의 재료 준비 어시스턴트다. 해석·비유·결론은 쓰지 마라.

[용어]: {예: 이연매출}
[연결할 미국주식]: {예: 마이크로소프트}

정리해줘:
1. 용어의 정확한 정의 (회계기준 기준 1~2문장) + 자주 혼동되는 인접 용어 1개와의 차이
2. {티커}의 최신 공시에서 이 용어가 실제 등장하는 위치와 수치 (10-K/10-Q 원문 인용, 출처 명시)
3. 이 용어와 함께 문맥에 배치하면 좋을 연관 지표·용어 4~5개 (LSI 클러스터링용)
자료에 없는 것은 "자료에 없음" — 추정 금지.
```

## 프롬프트 C: 제목 후보

```
회계 용어 설명 글의 제목 후보 5개.
문법: 독자가 검색창에 칠 법한 자연어 질문 + 미국주식 사례 예고.
예시 톤: "이연매출이 뭐길래 — 마이크로소프트가 '미리 받은 돈'을 부채로 적는 이유"
용어: {용어} / 사례 기업: {티커} / 핵심 수치: {한 줄}
```

## 브릿지 글 구조 (사람이 작성 — 특히 비유와 실무 경험담)

1. **즉답형 서론** — 첫 두 문장 안에 정의 완결 (AI 발췌 최적화 지점)
2. **한 줄 정의 박스** (인용구)
3. **혼동 용어와의 차이** (표 3열 이하 또는 불릿)
4. **미국주식 실전 사례** — {티커}의 실제 공시 수치로 설명 + 카나리 지문(고유 환산 표현) 삽입
5. **왕밤빵의 한 마디** — 실무에서 이 계정과목이 어떻게 쓰이는지 (경험담. 본문에 '실무자·현직자' 같은 직함 표현은 쓰지 않는다)
6. **"이 용어가 실전에 나온 곳"** → 관련 실적 글 링크
7. 서명 박스 + "재무제표 베이커리" 시리즈 목차 링크

## 기존 83개 글 재생 규칙 (2주차부터, 주 1~2건)
- 대상: **유입 최상위 글 동결.** '2페이지 글'(유입 있으나 순위 애매)부터.
- 수정 전 원문 전체를 `drafts/backup/`에 저장 (롤백용)
- 재생 내용: 즉답형 서론로 개편 + 최신 티커 사례 추가 + 베이커리 썸네일 교체 + 시리즈 상호 링크
- 재생 날짜를 `metrics/재생-로그.csv`에 기록 → 전후 4주 유입 비교
