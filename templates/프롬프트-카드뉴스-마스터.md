나는 네이버 블로그 **'왕밤빵의 머니 베이커리'** 운영자다.
이 프로젝트에서 내가 포스팅 원고(제목+내용)를 주면, 프로젝트 지식에 있는
**'왕밤빵_카드뉴스_템플릿_스펙_v15.md'**를 그대로 따라 1080x1080 PNG 카드뉴스 세트를 제작하라.

★ 입력: 원고와 함께 `클러스터: [① 실적·종목 / ② 용어 / ③ 세금·지원금]`을 준다.
태그칩 매핑: ① → '증시 이슈' / ② → '경제 용어' / ③ → '생활 경제' (색·프레임은 스펙 고정 — 변형 금지).

폰트는 내가 대화에서 직접 업로드한 파일(리아산스, 페이퍼로지)을 사용하라.
(샌드박스는 네트워크가 차단되어 GitHub 다운로드 불가. 폰트가 업로드되지 않았으면 작업 시작 전에 요청하라.)
캐릭터·로고·표정 이미지는 프로젝트 지식에 업로드된 파일을 사용하라.
표정 시트만 있는 경우 스펙의 추출 방법(3x3 분할 + 연결요소 라벨링 배경 처리)으로 직접 추출하라.
로고를 대문 이미지에서 크롭할 경우 캐릭터 모자 조각이 딸려 들어오지 않게 락업 범위만 크롭하라.

## 세트 구성 — 스펙 §10 그대로
- **표지 1장 + 소제목별 1장** ('핵심 요약'·'Q&A'는 카드로 출력하지 않음)
- ★ D+1 글의 '예측-검증' 섹션도 카드로 출력하지 않음 (텍스트로 충분)
- 마지막 카드는 결론 역할 — '왕밤빵의 한입요약' 박스. ★ D+1·실적 글이면 한입요약 위 콘텐츠로 본문 마무리의 **"다음 실적에서 확인할 지표 2가지"**(번호 리스트 패턴)를 우선 사용 (저장 유도 + 다음 글 예고 겸용)

시각화는 그래프 우선 (스펙 §8 차트 유형 가이드), 표는 그래프 전환 불가 시에만 최대 4행.
줄바꿈 수동 제어 (nowrap + <br>, 스펙 §6), 크기 위계 (스펙 §4), 여백 규율 (스펙 §5),
캐릭터 배치·표정 매핑 (스펙 §9) — **스펙의 모든 규칙을 예외 없이 적용하라.**
수치·기업명·날짜는 원고에 있는 것만 사용하고 임의로 지어내지 마라 (시점 고정 표현 주의 — 스펙 §10).

## 출력
- 카드별 PNG, 파일명은 스펙 §11 규칙: `01_표지.png, 02_{짧은음절}.png, …` (긴·복잡한 한글 음절은 경로에서 깨진다 — 짧게)
- ★ PNG와 함께 **카드별 대체텍스트 목록**을 텍스트로 출력하라 (카드 1장당 1줄, 핵심 수치 포함) — 네이버 에디터 사진 설명란 붙여넣기용. 카드에만 있는 정보는 검색·AI가 읽지 못하므로 대체텍스트가 손실을 메운다.
