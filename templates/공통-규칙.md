# 공통 규칙 — 모든 발행 글에 적용

## 1. 발행 전 팩트체크 게이트 (3분, 생략 불가)
- [ ] AI(CC/챗봇)가 산출한 **모든 수치**를 1차 자료(보도자료·10-Q·어닝콜)와 대조했다 — 전수 대조, 샘플 아님
- [ ] 글에 인용한 출처 링크가 실제로 열리고, 해당 수치가 그 문서에 있다
- [ ] 해석 문장과 결론은 **내가 직접 썼다** (AI는 재료 준비까지만)
- [ ] 단정적 매수·매도 추천 표현이 없다 ("~해야 한다" → "~를 확인할 필요가 있다")

## 2. 제목 문법 — [메인 키워드 선두] + [질의의도 세부 키워드] + ['후킹' 인용부호]
네이버는 검색 기반: **메인 키워드와 질의의도가 제목에 담기는 것이 상위노출의 제1 조건.** 브랜드명(머니 베이커리)은 검색량이 없으므로 제목에 넣지 않는다.
- **클러스터 1 (실적 해석):** `[종목명+실적/주가(메인)] + [급등락·이유(질의의도)] + '후킹'`
  - 예: `브로드컴 실적 발표, AI 매출 급증에도 '이 숫자'가 발목 잡았다`
  - 예: `SK하이닉스 주가 전망, 목표주가 상향에도 '뜻밖의 변수'`
- **클러스터 2 (브릿지):** `[용어+뜻/차이(메인)] + [사례·상황(세부)]` — 검색창에 칠 문장 그대로.
  - 예: `감가상각 뜻, 테슬라 공장으로 3분 만에 이해하기`
- **클러스터 3 (실용):** `[제도명+핵심 조건(메인)] + [시한·금액(세부)] + '후킹'`
  - 예: `재산세 카드 납부 혜택 총정리, '이 카드'는 무이자 안 됩니다`
- 어그로 단정("무조건", "폭등 확정")은 금지하되, '후킹' 인용부호("~라는데" 제외한 '이 숫자'·'뜻밖의 변수' 류)는 적극 활용 — 선정 메이트들의 실전 문법.

## 3. 글 구조 (GEO 6원칙)
1. **즉답형 서론:** 첫 문단에 결론. 인사말·서론 금지.
2. **3초 요약 박스:** 인용구 기능 사용. 오늘의 종목/핵심 이슈/Bull/Bear (클러스터 1) 또는 한 줄 정의 (클러스터 2)
3. **소제목(H2/H3)** 으로 위계 분리
4. **숫자 + 해석 결합:** 수치 나열 금지 — "매출 10% 증가"가 아니라 "물량 확대 때문인지 단가 인상 때문인지" 분해
5. **리스크 동등 비중** + 예측이 틀렸으면 투명하게 인정 (추적형 섹션)
6. **다음 글 연결:** "다음 분기에 확인할 지표 2가지"로 마무리

## 3.5 표기 금지 규칙 (운영자 확정, 9/2)
- **긴 줄표(—) 금지** — AI 생성 글의 대표 지문. 쉼표·마침표·쌍점·괄호로 대체.
- **본문 이모지 금지** — 네이버 에디터에서 입력 불안정. 마커는 ☞ 같은 특수문자로.
- (기존 유지) 태그칩·썸네일 이모지 금지, AI 상투어·금칙어 목록은 본문 마스터 참조.
- **초안 본문에 편집 노트 금지 (9/2 확정)** — `[확인 필요]`, `(→ 예고·링크 자리)`, `(서명 박스 템플릿)` 같은 지시문은 운영자가 그대로 복사하면 사고. 확인 사항은 재료 파일·완료 보고에만.
- **해석은 AI가 ☞ 마커로 소제목당 1개, 최대 2줄 작성** — 운영자가 본문 작성 중 검토·수정 (9/2 확정, 플레이스홀더 방식 폐지). 핵심 요약은 3~5불릿 1문장씩, Q&A는 Q/A 줄바꿈, 출처는 기관명만.

- 발행 전 **모바일 미리보기** 확인 (독자 대부분이 모바일 유입)

## 6. 카나리 지문 (측정용) vs 시그니처 (브랜딩용) — 혼동 금지
- **시그니처** = 매 글 반복되는 브랜드 문구 (예: "BAKE MONEY"). 인용 측정에 못 쓴다.
- **카나리** = **글마다 고유한 비유·구문 조합** (2026-09-02 개정: 수치 환산 방식은 본문 프롬프트의 '환산 금지' 원칙과 충돌해 폐기. 숫자는 절대 새로 만들지 않는다 — 표현만 고유하게).
  - 예: "장부에서 공장이 녹아내리는 속도", "가이던스라는 이름의 예고편"
- 발행 시 카나리 문구를 `planning/` 편성표의 카나리 컬럼에 기록 → 1~2주 후 해당 주제를 AI 브리핑에 질문해 지문 등장 여부 확인

## 7. 상호 링크 규칙
- 용어 글 ↔ 실적 글: "이 용어가 실전에 나온 곳 → [실적 글]" / 실적 글의 용어 풀이 박스 → 용어 글 링크
- 모든 실적 글은 분기 캘린더 허브에 링크
