# 클러스터 1 프롬프트 — 실적 D+1 해석 글

역할 분담 (CEO 플랜 확정 사항):
- **AI가 하는 것:** 1차 자료 요약, 수치 표, 컨센서스 대비, 구조 스켈레톤 — 재료 준비까지만
- **사람(왕밤빵)이 하는 것:** 해석 문장, 결론, "회계쟁이의 행간" — 이게 이 채널의 해자

---

## 프롬프트 A: 재료 준비 (발표 직후, AI에 붙여넣기)

```
너는 미국주식 실적 자료 정리 어시스턴트다. 해석이나 의견은 절대 쓰지 마라 — 사실 정리만 한다.

[티커]: {예: AVGO}
[자료]: {보도자료/10-Q/어닝콜 원문 붙여넣기 또는 링크}

다음을 정리해줘:
1. 핵심 수치 표 (3열 이하): 이번 분기 실적 vs 컨센서스 vs 전년 동기 — 매출, EPS, 그리고 이 회사의 핵심 지표 1개
2. 세그먼트별 매출과 증감 (물량 요인인지 단가 요인인지 자료에 언급이 있으면 그대로 인용)
3. 가이던스: 회사가 제시한 다음 분기/연간 전망 원문
4. 어닝콜에서 애널리스트 질문이 집중된 주제 상위 3개 (질문 원문 요약)
5. 자료에 나온 리스크 요인 (회사 스스로 언급한 것)
6. 이 글에서 풀이가 필요할 회계·투자 용어 후보 3개
각 항목마다 출처(문서명, 페이지/타임스탬프)를 붙여라. 자료에 없는 내용은 "자료에 없음"이라고 써라 — 추정 금지.
```

## 프롬프트 B: 제목 후보 (재료 준비 후)

```
미국주식 실적 해석 글의 제목 후보 5개를 만들어줘.
문법: 구체 숫자 + 인용부호 + 이유 예고. 어그로 단정 금지 ("~라는데", "폭등", "무조건" 금지).
독자: 실적발표 직후 "왜 올랐지/왜 떨어졌지"를 검색하는 보유자.
재료: {핵심 수치와 쟁점 1~2줄}
예시 톤: "매출 36% 늘었는데 주가는 하락" 템퍼스 AI 실적의 진짜 쟁점
```

## D+1 글 구조 (사람이 작성)

1. **즉답형 서론** — 주가가 왜 움직였는지 한 문단 결론
2. **예측-검증 섹션** — "발표 전 제가 적어둔 관전 포인트는 ①②③이었습니다. 결과는…" (planning/의 D-1 메모 공개. 맞은 것과 틀린 것을 똑같은 비중으로)
3. **3초 요약 박스** — 종목/이슈/Bull/Bear
4. **수치 분해 + 왕밤빵의 해석** (프롬프트 A의 재료 + 내 해석. 본문에 '회계쟁이·실무자' 직함 표현 금지)
5. **용어 풀이 박스** (용어 글 링크)
6. **리스크** (동등 비중)
7. 서명 박스 + 캘린더 허브 링크 (별도 마무리 절은 쓰지 않는다, 9/3 확정)

## D-1 관전 포인트 메모 (발표 전날, planning/에 커밋 — 발행 아님)

```
## {티커} {발표일} 관전 포인트 (D-1)
1. 컨센서스: EPS $__ / 매출 $__
2. 전분기 대비 핵심 지표: {지표명, 직전 값}
3. 왕밤빵의 관전 포인트: {한 문장}
```
커밋 타임스탬프가 "발표 전에 적었다"는 증거가 된다.
