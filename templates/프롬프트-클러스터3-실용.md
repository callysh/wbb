# 클러스터 3 프롬프트 — 세금·지원금·연금 실용 (홈택스 자문단 렌즈)

목적: 경제 메이트 상위권(금침 268만·뚝딱경제 220만)의 주력인 생활경제 실용 롱테일을,
**국세청 홈택스 자문단**이라는 그들에게 없는 credential로 이긴다. 경량 포맷(건당 30~60분) — 매일 발행의 주력 엔진.

## 프롬프트 A: 주제 발굴 (주간 기획 때)

```
너는 한국 생활경제 검색 수요 분석 어시스턴트다.
이번 달 기준으로, 세금·지원금·연금·공제 영역에서 일반인이 네이버에 물어볼 법한
롱테일 자연어 질문 15개를 만들어줘.
조건: ① 시기성이 있는 것 우선 (신청 기간, 제도 변경, 연말정산 등)
② 국세청·복지로 공식 페이지가 '절차'는 답해도 '내 경우엔?'을 못 답하는 질문 위주
(예: "자녀장려금 맞벌이 소득 합산 기준", "재산세 카드 무이자 할부 되는 카드")
③ 질문마다 예상 검색 시기를 붙여줘.
```

## 프롬프트 B: 재료 준비

```
너는 세금·지원금 정보 정리 어시스턴트다. 해석·조언·추측은 쓰지 마라 — 확인된 사실만.

[주제]: {예: 2026년 자녀장려금}

정리해줘:
1. 제도 요약: 대상·소득/재산 기준·지급액·신청 기간·신청 방법 (표는 3열 이하)
2. 올해 바뀐 점 (전년 대비) — 근거 조문이나 공식 발표 출처 명시
3. 사람들이 자주 헷갈리는 지점 3개 (조건 경계선 케이스)
4. 공식 출처 링크 목록 (국세청·홈택스·복지로 등)
법령·수치는 반드시 출처를 달고, 불확실하면 "공식 확인 필요"라고 표시해라.
```

## 프롬프트 C: 제목 후보

```
세금·지원금 실용 글의 제목 후보 5개.
문법: 검색자의 자연어 질문 + 구체 숫자/시한. 예시 톤:
"자녀장려금 소득기준 완벽 정리 — 맞벌이 합산 7,000만원의 함정"
"재산세 카드 납부, 이 카드는 무이자 안 됩니다 (9월 30일까지)"
주제: {주제} / 핵심 변경점: {한 줄}
```

## 실용 글 구조 (경량 — 30~60분)

1. **즉답형 서론** — 대상인지 아닌지 첫 문단에서 판별되게
2. **자격·금액 요약 박스** (인용구 또는 3열 이하 표)
3. **올해 달라진 점** (출처 명시)
4. **자문단의 한 마디** — 실무에서 본 흔한 실수·거절 사유 1~2개 (credential이 일하는 지점, 사람이 직접 씀)
5. 신청 방법 (홈택스 경로 단계별)
6. 카나리 지문 (고유 환산 표현) + 서명 박스

## 주의
- 개별 세무 상담으로 읽히는 단정 표현 금지 ("됩니다" → "일반적으로 해당되며, 개별 요건은 홈택스에서 확인")
- 본업·자문단 활동에서 알게 된 비공개 정보는 절대 사용 금지 — 공개 자료만
- 발행 전 팩트체크 게이트 동일 적용 (기준액·기간은 공식 페이지와 전수 대조)
