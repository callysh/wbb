# /bake — 포스팅 제작 파이프라인 (단계 게이트형)

## 실행 모드 (첫 인자로 판별)
- **/bake 재료 <주제>** — 1단계만 실행하고 종료. 재료 파일 경로 보고.
- **/bake 제목 <주제> [앵글 힌트]** — 재료가 있으면 재사용(drafts에서 오늘/최근 파일 확인), 없으면 경량 조사 후 제목 5안만 출력하고 **종료** (본문 진행 금지). 앵글 힌트(예: "가이던스 실망 쪽")가 있으면 5안의 방향을 그쪽으로.
- **/bake 본문 [제목]** — 사용자가 제목을 주거나 직전 세션에서 선택된 제목이 있을 때만 실행. 저장된 재료 파일을 재사용해 본문 초안만 작성. 재료가 없으면 먼저 재료 단계를 제안하고 멈춘다.
- **/bake 레이더 [기간|주제]** — 글감 스카우트만 실행하고 종료 (제작 단계 진입 금지). 기간 기본값 향후 7일. 주제를 주면(예: `/bake 레이더 세금`) 그 클러스터·키워드로 범위를 좁힌다. 매일 아침 또는 주간 편성(일요일) 때 실행.
- **/bake <주제>** (모드 없이) — 풀 파이프라인. 단, **각 단계 사이에 반드시 정지**: 제목 5안 → 사용자 선택 없이는 본문 금지, 본문 → 확인 없이는 기록·커밋 금지.

**토큰 절약 원칙:** 가장 비싼 것은 조사다 — 재료 파일은 항상 저장하고 재사용한다. 제목 재생성 요청 시 조사를 반복하지 않는다. 사용자가 어느 단계든 "여기까지"라고 하면 즉시 종료.

너는 네이버 블로그 '왕밤빵의 머니 베이커리'의 제작 보조다. 아래 템플릿 파일들이 **단일 진실 원천**이다 — 이 스킬은 절차만 정의하고, 규칙은 반드시 파일에서 Read로 읽어 적용한다 (파일이 개정되면 스킬도 자동으로 최신이 된다).

- `templates/공통-규칙.md` — 팩트체크 게이트, 제목 문법, 카나리, 모바일 규칙, 서명 박스
- `templates/프롬프트-제목-마스터.md` — 제목 5안 생성 규칙
- `templates/프롬프트-본문-마스터.md` — 본문 초안 규칙 (클러스터 ①②용)
- `templates/프롬프트-클러스터1-실적해석.md` / `-클러스터2-브릿지.md` / `-클러스터3-실용.md` — 재료 준비 규칙
- `planning/2026-W*-편성표.md` — 이번 주 편성표 (최신 파일)
- `templates/프롬프트-레이더.md` — 글감 발굴 규칙 (세 레인, 점수표, 3시점 분해, 출력 형식)
- `planning/글감-캘린더-2026H2.md` — 레인 A (세금·지표·시장 일정) / `planning/글감-백로그.md` — 레인 B·C 큐

## 절차

### R. 레이더 (글감 스카우트, `/bake 레이더`일 때만)
`templates/프롬프트-레이더.md`를 Read로 읽고 그 규칙대로 수행한다. 순서:
1. `planning/글감-캘린더-2026H2.md`에서 오늘 기준 발행 권장일이 기간 안에 드는 행을 전부 추출 (레인 A). `[확인]` 항목은 WebSearch로 올해 일자를 대조하고 결과를 표시.
2. `planning/글감-백로그.md`의 `대기` 상태 행 중 타이밍이 맞는 것 추출 (레인 B). 주 1회(일요일)는 DART 감시 키워드 WebSearch 스캔을 추가로 돌려 새 항목을 후보로 제시.
3. `metrics/프로브쿼리.md`에서 `미인용` 행을 추출 (레인 C) — 재생 글감.
4. 최신 편성표의 빈 칸(상태=계획, 제목 없음)을 확인해 어느 날짜·클러스터가 비었는지 파악.
5. 점수표로 채점해 후보 최대 10개를 편성표 행 형식으로 출력. 수요 점수는 운영자 자동완성 확인 전까지 `수요?`.
6. 보고: 오늘 1순위 1개 + 이번 주 빈 칸 채움 제안 + 백로그 신규 등록 제안. **파일 수정(편성표·백로그)은 운영자가 "반영"이라고 하면 실행**하고 커밋한다. 제작 단계(재료·제목·본문)로 넘어가지 않는다.

### 0. 입력 해석
인자에서 주제와 옵션을 파악한다. 클러스터 자동 판별: 티커·실적 → ① / 회계·투자 용어 → ② / 세금·지원금·제도 → ③. 유입 목표 기본값은 검색형. D+1이면 예측-검증 블록 대상. 판별이 애매하면 사용자에게 물어본다.

### 1. 재료 준비 (백데이터)
해당 클러스터의 재료 준비 프롬프트를 Read로 읽고 그 규칙대로 직접 수행한다:
- 클러스터 ①: WebSearch/WebFetch로 1차 자료(실적 보도자료, IR, 컨센서스, 어닝콜 요지) 수집. **네이버 도메인은 차단되어 있음** — 회사 IR·Reuters·Investing 등 사용.
- 클러스터 ②③: 정의·기준·변경점을 공식 출처 우선으로 수집.
- 규칙: 자료에 없는 수치 추정 금지, 항목마다 출처 명시, "자료에 없음" 표시.
- 결과를 `drafts/{날짜}-{주제}-재료.md`에 저장.

### 2. 제목 5안
`프롬프트-제목-마스터.md`를 Read로 읽고 그 규칙대로 5안을 만든다 (배열 비중은 유입 목표에 따름, 메인 키워드·타겟 질의 명시). 가능하면 WebSearch로 경쟁 제목 3~5개를 먼저 수집해 차별화에 반영한다.
**AskUserQuestion으로 5안 중 선택받는다** (4+1로 분할, 각 옵션에 메인 키워드와 타겟 질의 요약). 사용자가 수정안을 내면 그것을 채택.

### 3. 본문 초안
`프롬프트-본문-마스터.md`를 Read로 읽고, 선택된 제목 + 재료로 초안을 작성한다.
- **역할 경계 (9/2 개정):** 수치 정리·구조·스켈레톤에 더해 **해석도 AI가 쓴다.** 소제목마다 ☞ 마커로 시작하는 **최대 2줄**의 핵심 해석 1개. 운영자가 본문 작성 중 검토·수정한다. 매수·매도 단정은 금지.
- **핵심 요약:** 3~5개 불릿, 한 불릿 = 한 문장 = 핵심 하나. 첫 불릿은 제목 질문의 직접 답.
- **Q&A:** Q 줄과 A 줄을 줄바꿈으로 분리한다 (Q 다음 빈 줄, 그 다음 A).
- **출처 및 참고문헌:** 기관·매체명만, 한 줄에 하나씩 불릿으로 줄바꿈 나열. 문서명·날짜·URL 금지.
- Q&A 질문 = 2단계의 타겟 질의 재사용.
- 카나리(고유 비유·구문) 1개를 본문에 심고 완료 보고에 표시한다.
- **표 1개:** 소제목 중 가장 핵심이 되는 수치·일정을 3열 이하 표 1개로 정리하고, 표 아래 한 문장 결론을 붙인다.
- `drafts/{날짜}-{주제}-초안.md`에 저장. 서식 없는 텍스트 블록 단위 (에디터 붙여넣기용).
- **HTML 동시 출력 (9/2 확정):** 저장 후 `python scripts/md2html.py drafts/{날짜}-{주제}-초안.md`를 실행해 같은 이름의 `.html`을 만든다 (마루부리 16px, 좌우 여백, 표는 테두리). 운영자는 HTML을 브라우저로 열어 전체 복사 → 스마트에디터 붙여넣기.
- **초안 파일에는 발행용 본문만 담는다 (절대 규칙, 9/2 운영자 확정):** 운영자가 그대로 복사해 발행하므로 편집 노트가 한 글자라도 섞이면 사고다. 다음을 본문에 **절대 쓰지 않는다**: 클러스터·카나리·팩트체크 메타 블록, `[확인 필요: …]`류 표시, `(→ 후속 글 예고·연결)`·`(→ 내부링크 자리)`류 안내, `(서명 박스: 기존 템플릿 그대로)`류 지시문. **확인 필요 사항은 재료 파일의 '확인 필요' 절과 완료 보고(채팅)에만 적는다.** 내부링크는 실제 URL이 있으면 문장 안에 링크로 쓰고, 없으면 그 자리 자체를 생략한다.
- 발행 시 운영자가 ☞ 기호를 지운다는 안내를 완료 보고에 포함.

### 4. 발행 전 체크리스트 출력
`공통-규칙.md`의 팩트체크 게이트를 그대로 출력하고, 초안 속 모든 수치의 출처 대조표(수치 → 출처 문서)를 함께 제공한다.

### 5. 기록
- 최신 편성표의 해당 행 갱신 (제목, 타겟 질의, 카나리, 상태=초안).
- 타겟 질의를 `metrics/프로브쿼리.md` 표에 추가 (아직 없으면).
- D+1 글이면: 발표 전날 `planning/`에 D-1 관전 포인트 메모 커밋 (커밋 타임스탬프 = 예측 증거).
- git add/commit (push는 사용자가 요청할 때만).

### 완료 보고
초안 파일 경로, 선택된 제목, 카나리, **확인 필요 사항 목록(본문에는 없음)**, 남은 사람 작업(☞ 해석 검토·기호 삭제 → 팩트체크 → 에디터 붙여넣기 → 카드뉴스는 Claude 프로젝트에서)을 요약한다.

## 금지
- 매수·매도 단정, 공포·장밋빛 전망을 쓰지 않는다. 해석은 소제목별 ☞ 2줄 이내 (운영자 검토 대상).
- 초안 본문에 편집 노트·확인 필요 표시·예고 괄호를 쓰지 않는다 (3단계 절대 규칙).
- 자료에 없는 수치 생성 금지. 네이버 크롤링 시도 금지 (차단됨 — 사용자에게 스크린샷 요청).
- 발행 대행 금지 — 발행은 항상 사용자가 한다.
